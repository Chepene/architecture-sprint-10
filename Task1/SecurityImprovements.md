# Меры по увеличению безопасности инфраструктуры

| Направление | Конкретные меры |
|:------------|:----------------|
| Active Directory | Включить Kerberos шифрование, настроить строгие политики RBAC (разные OU для врачей, кассиров, бухгалтеров, склада). |
| LDAP | Перевести LDAP на LDAPS (шифрование через SSL/TLS). |
| Файловый сервер | Включить BitLocker на дисках хранения Excel-файлов + включить контроль версий для критичных данных. |
| ККМ и 1С | Настроить туннель через VPN или использовать IPsec между ККМ и сервером 1С для шифрования TCP-потока. |
| Exchange | Настроить шифрование почты через S/MIME + правила DLP для писем, содержащих PII/PHI. |
| Аудит | Включить политику аудита доступа к файлам, LDAP-запросам, письмам. Настроить мониторинг событий безопасности. |

# Краткий план обновления диаграммы потоков данных

| Компонент | Защита, которую добавим |
|:----------|:-----------------------|
| Пациент → Администратор | Шифрование SSL/TLS на портале записи |
| Администратор → Excel-файл (журнал) | Классификация PII, PHI + Шифрование хранения файлов + Аудит доступа |
| Пациент → Оплата кассиру | Безопасный туннель TCP/IP (IPsec или VPN) для передачи в ККМ |
| ККМ → 1С Бухгалтерия | Шифрование TCP/IP (VPN/IPsec) + Аудит передачи чеков |
| Врач → Журнал пациента | Классификация PHI, строгий RBAC, аудит изменений |
| Бухгалтер → 1С Бухгалтерия | Financial Data: Шифрование хранения и аудита |
| Складской сотрудник → 1С Торговля и Склад | Business Data: Шифрование хранения, контроль доступа |
