# Аудит мер безопасности данных (Медикаменте)

## Таблица проблем безопасности для процессов As-Is

| № | Процесс | Проблемы с безопасностью и конфиденциальностью |
|:--|:--------|:-----------------------------------------------|
| 1 | Пациент записывается к врачу | - Отсутствие аудита действий сотрудников.<br>- Данные пациента передаются без защиты.<br>- Нет разграничения доступа к расписанию врачей. |
| 2 | Пациент оплачивает приём | - Нет шифрования передачи данных между КММ и 1С. |
| 3 | Врач просматривает и редактирует данные | - Нет разграничения доступа между врачами.<br>- Нет шифрования медицинских данных.<br>- Отсутствие аудита действий сотрудников.<br>- Возможность полного копирования базы любым пользователем с доступом. |
| 4 | Ведение бухгалтерии | - Уязвимость файлового режима 1С:<br>  • Нет разграничения прав по пользователям.<br>  • Нет шифрования данных на хранении.<br>  • Нет централизованного аудита.<br>  • Возможность полного копирования базы любым пользователем с доступом. |
| 5 | Управление складом | - Уязвимость файлового режима 1С:<br>  • Нет разграничения прав по пользователям.<br>  • Нет шифрования данных на хранении.<br>  • Нет централизованного аудита.<br>  • Возможность полного копирования базы любым пользователем с доступом. |
| 6 | Работа администратора ресепшена | - Нет разграничения доступа к данным пациентов.<br>- Нет шифрования файлов.<br>- Отсутствие аудита действий сотрудников.<br>- Возможность полного копирования базы любым пользователем с доступом. |
